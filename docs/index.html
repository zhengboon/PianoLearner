PianoLearner

A Synthesia-style step-by-step piano practice tool. Loads a MIDI file, listens through your microphone, and only advances when you've actually played the right note on a real piano.

How it works

  1. Load a MIDI file. The in-tree SMF Format 0/1 parser extracts NoteOn/NoteOff events.
  2. Group notes into chord slots using PianoBooster's two-threshold model (consecutive-gap + first-to-last-span).
  3. Open the microphone — 16-bit PCM mono at 44.1 kHz, 4 096-sample frames.
  4. Run each frame through McLeod Pitch Method (Tartini zero-crossing peak picker, in-tree port of TarsosDSP's algorithm). Returns the dominant pitch.
  5. Match against the current slot within ±50 cents. When every unique pitch in the slot has been heard, the playhead advances.

Download & build

Prebuilt artifacts are on the Releases page. To build from source:

Android

cd android
docker compose run --rm build
adb install -r app/build/outputs/apk/debug/app-debug.apk

Min SDK 26, target SDK 34. Docker image includes Android cmdline-tools, platform-34, build-tools 34.0.0, and Gradle 8.7.

Windows desktop

cd desktop
docker compose run --rm build           # compile + unit tests (Linux container)
gradlew.bat --no-daemon createDistributable  # native .exe with bundled JRE (host JDK 17)

jpackage is OS-bound — Windows installer must be built on Windows. The Docker step verifies code health; the host step produces a runnable folder.

Stack

  • Kotlin 1.9.24 across both platforms
  • Android: Jetpack Compose (BOM 2024.06), AGP 8.5, kotlinx-coroutines-android 1.7.3
  • Desktop: Compose Multiplatform 1.6.10, JDK 17 (Eclipse Temurin)
  • Pitch detection: in-tree McLeod Pitch Method (~200 lines, no external dep) — ported from TarsosDSP
  • MIDI parser: in-tree SMF Format 0/1 reader, ~200 lines
  • Chord grouping: PianoBooster two-threshold model
  • Build: Gradle 8.7, Docker for hermetic CI

Verification

The desktop project includes an offline TestPlayer that synthesizes audio for every slot of a MIDI file and runs it through the exact PitchDetector + PitchMatcher chain the live app uses.

  • 613 / 613 chord slots in Pachelbel's Canon
  • 500 / 500 randomly-sampled MIDIs from a 13 536-file generated chord corpus (ldrolez/free-midi-chords)
  • 27 JVM unit tests across both projects
cd desktop
gradlew.bat -PmidiPath="C:\path\to\file.mid" testPlayer
gradlew.bat -PmidiPath="C:\path\to\corpus" -PsampleSize=500 testPlayer
